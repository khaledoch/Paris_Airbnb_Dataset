# Power BI dashboard plan

This folder stores the strategy for the final investor- and traveler-facing dashboard.

## Dashboard objective
Present a concise, interactive view of Paris Airbnb supply, price, occupancy, revenue proxy, property characteristics, host status, and review quality.

## Dashboard sections
1. Introduction and navigation
2. Main dashboard with four KPI cards and four charts
3. Neighborhood drill-through dashboard

## Main dashboard visuals

- average nightly price by room type
- occupancy rate by neighborhood
- listing count by room type
- price versus occupancy by neighborhood

## Drill-through visuals

The neighborhood drill-through uses the selected `neighborhood` and compares:

- property type and nightly price
- room type and nightly price
- host segment performance
- property type price versus review score

## Data source

When PostgreSQL views cannot be used because of storage constraints, Power BI uses the single denormalized export generated by `queries/06_powerbi_listing_export.sql`. This keeps slicers and visuals interactive without relationships between separate summary CSV files.

## Design intent
The dashboard should be polished, readable, and limited to metrics supported by the SQL and Python work in this repository.
